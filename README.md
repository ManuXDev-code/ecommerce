## 📋 Sobre el proyecto

**Ecommerce** es una plataforma de comercio electrónico desarrollada con **Laravel 12**, diseñada para gestionar productos, usuarios y operaciones propias de una tienda online.

El proyecto utiliza una arquitectura **MVC**, base de datos MySQL y herramientas modernas del ecosistema Laravel para ofrecer una aplicación organizada, escalable y fácil de mantener.

---

## ✨ Características

- 🛍️ Catálogo de productos
- 👤 Gestión de usuarios
- ❤️ Sistema de productos favoritos
- 🛒 Carrito de compras
- 📦 Gestión de pedidos
- 💳 Integración de pagos
- 🗄️ Gestión de base de datos
- 🔐 Autenticación de usuarios
- 📱 Interfaz adaptable
- ⚙️ Panel de administración
